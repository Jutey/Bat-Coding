## Skill Levels

Each skill has 5 levels. Levels are earned by completing lessons and projects — not by passing tests.

### OUTPUT
| Level | What You Can Do |
|-------|----------------|
| 1 | Print text with `echo` |
| 2 | Multi-line output, blank lines, `echo.` |
| 3 | Color-coded terminal, custom titles |
| 4 | ASCII art, professional menus |
| 5 | Full multi-screen interactive displays |

### DATA STORAGE
| Level | What You Can Do |
|-------|----------------|
| 1 | Store a value with `set` |
| 2 | Display variables with `%` |
| 3 | Take input with `set /p` |
| 4 | Multi-variable systems (health, gold, inventory) |
| 5 | Save and load data from files |

### CONTROL FLOW
| Level | What You Can Do |
|-------|----------------|
| 1 | Understand true/false |
| 2 | Write a basic `if` statement |
| 3 | Multiple conditions and outcomes |
| 4 | Branching stories and decision trees |
| 5 | Complex multi-condition logic systems |

### LOOPS
| Level | What You Can Do |
|-------|----------------|
| 1 | Write a label and `goto` |
| 2 | Create a controlled loop |
| 3 | Game loops with input |
| 4 | Animation and timers |
| 5 | Complex loop systems with multiple exit conditions |

### FILES
| Level | What You Can Do |
|-------|----------------|

## The Debugging Track

Debugging is its own skill in this curriculum — not an afterthought.

Most coding courses teach debugging as "what to do when things break."  
This course teaches debugging as a **first-class skill** from lesson 1.

Every lesson has a Break/Fix section. Every boss battle is a pure debugging challenge.  
By World 5, a student's debugging skill should be significantly higher than their output skill — because debugging is practiced at every lesson, while output skills plateau once learned.
