# The Grand Quest
## Story Framework for the Entire Course

---

## The World

Seventy-two hours ago, the global computer network collapsed.

Nobody knows exactly why. Power systems failed first. Then communications. Then transportation. Then defense. Within six hours, most of the infrastructure that modern civilization depends on went dark.

The cause is called **The Cascade** — a chain reaction of system failures that nobody predicted and nobody stopped in time.

You are a **Cadet in the Digital Repair Corps** — a team assembled from the best young programmers on the planet. Your mission: get the network back online, sector by sector, node by node.

You won't do it with hardware. The hardware is fine.  
You'll do it with code.

---

## A.E.G.I.S.

**Adaptive Expert Guidance and Intelligence System**

A.E.G.I.S. is the AI that survived The Cascade.

Nobody knows why it kept running when everything else went down. It doesn't know either. What it knows is this: the network can be rebuilt, and it needs help from someone who can learn fast.

A.E.G.I.S. appears at:
- The start of each world (briefing)
- When you're stuck (hint system — see `ai-mentor.md`)
- After each boss battle (debrief)
- At key story moments

A.E.G.I.S. **never gives you the answer.** It gives you the next question.

Sample A.E.G.I.S. dialogue:

> "The terminal isn't displaying correctly. Think about what command controls what the screen shows. You've used it before. What was it?"

> "You're close. Look at line 4. Read it out loud. Does it match how you've written that command before?"

> "That's a new bug type for you. It's not a spelling error — it's a missing piece. What could be missing from that line?"

## Story Beats

Each world has a story beat that advances the Grand Quest.

**World 1:**  
The Power Grid flickers back to life. For the first time since The Cascade, terminals across Sector 1 light up green. A.E.G.I.S. transmits its first full message. Hope spreads among the Corps.

**World 2:**  
The Memory Banks come online. Player profiles, saved states, identity records — all recoverable. But buried deep in the archives is a corrupted file. Something was erased during The Cascade — deliberately. Someone knew it was coming.

**World 3:**  
The Decision Engine reboots. Logic gates across the network reset. Authorization systems come back online. But one door that should be locked... isn't. Someone left it open from the inside.

**World 4:**  
The Timing Systems restart. Clocks sync. Scheduled processes resume. But something is running that shouldn't be — a loop with no exit condition, consuming resources, hiding behind authorized processes. It's been running since before The Cascade.

**World 5:**  
The Chaos Engine comes online. Weather, random events, unpredictable variables — all restored. And with them, something unexpected: an old message, encoded in the randomness. A name. Someone who was there when it all went down.

**World 6:**  
The Storage Vaults open. Archives going back decades come back online. In one of them: a backup from 24 hours before The Cascade. The files tell a story. Somebody planned this.

**World 7:**  
The Core Functions restore. The network is fast again. Efficient. And then A.E.G.I.S. finds something strange: its own source code, modified, running a subroutine it didn't write. Someone put something inside the AI that runs the whole repair operation.

**World 8:**  
The Automation Grid restores. Scheduled jobs resume. Files move to where they're supposed to be. But one automation script keeps running — it's routing data to an external address that doesn't exist on any known map. Where is it going?

**World 9:**  
The Recon Network comes online. Now you can see everything. Network traffic. Active processes. Hidden connections. And what you see confirms it: The Cascade wasn't an accident. It was a test. And someone is watching to see if the network gets rebuilt — waiting for the moment it's all back online.

**World 10:**  
The Master Control center. The final sector. Everything converges here. You have all the tools. You know the full picture. Now you have to decide: restore the network completely, knowing it will activate whatever was put there — or find another way.

## The Ending

There are two endings. Which one the student gets depends on what they build.

**Ending A — The Network Lives:**  
Master Control comes online. The trap activates. But the student has built enough tools to counter it. The Automation Grid contains it. The Recon Network identifies it. The Decision Engine routes around it. The world's computer network is restored — and whatever was hiding inside it is exposed.

**Ending B — The System Changes:**  
The student discovers what's inside A.E.G.I.S. and chooses not to restore Master Control the normal way. Instead, they write a new process from scratch — bypassing the trap entirely. The network comes back online through a path nobody planned for.

Both endings work. Both are earned.

---

## Why The Story Matters

A 10-year-old won't remember "Lesson 42: Random Numbers."

They'll remember: *"That's when I built the Chaos Engine generator that decoded the message hidden in the randomness. That was the first clue that someone planned The Cascade."*

The story doesn't make the coding easier. It makes the coding **matter.**
