# BAT CODING
### Computational Thinking for Kids — Through Batch Scripting

> "The kid doesn't learn Batch. The kid learns programming."

---

## What This Is

Most coding courses teach syntax.  
This one teaches **how to think like a programmer** — using Batch as the vehicle.

By the end, a kid aged 8–14 can:
- Build games, tools, and automation scripts
- Read code they've never seen before
- Debug broken programs
- Understand variables, logic, loops, functions, and files
- Transition into Python like they've already been there

## Every Lesson Works Like This

```
LEARN      → concept explained in plain language
PREDICT    → "what do you think this will do?"
RUN        → run the code and see
BREAK      → intentionally broken code to find the bug
FIX        → repair it yourself
CHALLENGE  → sandbox variation to build
REWARD     → achievement unlocked + story progress
```

The **Break** step is the most important.  
Real programmers debug. This course teaches it from lesson 1.
