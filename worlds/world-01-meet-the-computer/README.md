# WORLD 1 — Meet The Computer
## Sector: Power Grid

---

### Grand Quest Context

The world's computer network has gone dark.  
Power is offline. Screens are black. Nobody knows why.

You've been recruited as a Cadet in the Digital Repair Corps.  
Your first assignment: **restore the Power Grid.**

The Power Grid controls output — what the computer can display and say.  
Without it, nothing works. Not memory. Not logic. Not communication.

Your tools: a keyboard and a black screen with a blinking cursor.  
That's all you need.

---

### What You'll Learn

By the end of this world you can:
- Make the computer display text
- Control how the terminal looks
- Build a simple menu system
- Create your first text adventure
- Read code you've never seen and understand it

### Boss Battle — The Dead Terminal

The Power Grid's main terminal is alive — barely.  
It has 5 critical bugs. Find them. Fix them. Bring it online.

This is not a quiz. It's a repair job.
