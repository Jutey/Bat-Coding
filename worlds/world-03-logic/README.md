# WORLD 3 — Logic
## Sector: Decision Engine

---

### Grand Quest Context

The Memory Banks are online. The network remembers.  
But it still can't think.

The Decision Engine controls every choice in the system: who gets access, which path to take, what happens next. Without it, the network follows one fixed path — no matter what.

Restore the Decision Engine and the network gains judgment.

---

### What You'll Learn

- True vs false: how computers make decisions
- IF statements: the most important concept in all of programming
- String and number comparison
- Nested conditions and multiple outcomes
- Branching stories and choice systems

### Boss Battle — The Logic Bomb

Someone planted a logic bomb in the Decision Engine.  
The authorization gates are wrong — doors that should be locked are open, and doors that should be open are locked.

**7 bugs.** All logic errors — code that runs but does the wrong thing.  
This is the first boss where the code doesn't crash. It just does something wrong.  
Harder to spot than a typo. Requires understanding what the code should do.

---

### Story Beat

When the Decision Engine comes online, one door doesn't close correctly.  
A.E.G.I.S. traces it back to a manual override — entered from inside the system, 6 hours before The Cascade.

Someone with high-level access left a door open deliberately.  
The question is: where does that door lead?
