### The Big Idea

The student doesn't realize until this world how much they already know.

This world makes it explicit:

| Batch | Python |
|-------|--------|
| `echo Hello` | `print("Hello")` |
| `set name=Alex` | `name = "Alex"` |
| `echo %name%` | `print(name)` |
| `set /p name=Enter name: ` | `name = input("Enter name: ")` |
| `if "%x%"=="y"` | `if x == "y":` |
| `goto start` | `while True:` |
| `call :func` | `def func():` |
| `echo > file.txt` | `open("file.txt","w")` |

Same ideas. Different syntax.
