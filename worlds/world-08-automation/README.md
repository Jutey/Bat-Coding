# WORLD 8 — Automation
## Sector: Automation Grid

---

### Grand Quest Context

The network processes are running. But everything requires a human to start it.  
Open this program. Move that file. Check this folder. Rename those files.

The Automation Grid makes the network self-managing.  
Scheduled jobs run. Files go where they belong. Backups happen automatically.  
The network starts to feel alive.

This is also the world where kids realize: **programming isn't just for games.**

---

- Opening programs and websites from a script
- Shutdown and restart timers
- Copying, moving, and renaming files
- Creating folder structures
- Organizing a real desktop
- Building a daily automation script

### Boss Battle — The Data Storm

A runaway automation script is moving files to the wrong places.  
Important archives are being routed to temp folders. Critical backups are overwriting live data.

**8 bugs.** All file operation errors: source/destination swapped, wrong flags, missing checks.  
These bugs would actually mess up a real computer. Pay attention.

---

### Story Beat

When the Automation Grid comes online, the scheduled jobs resume.  
One of them — running every 6 hours since before The Cascade — sends a small packet of data to an external address.

A.E.G.I.S. traces the address.  
It doesn't exist in any known registry.  
But the packets keep going out.

> "Something on this network has been mailing home for months.  
> Now that we can see the traffic... we can follow it."
