# WORLD 2 — Variables
## Sector: Memory Banks

---

### Grand Quest Context

Sector 1 is online. The Power Grid is stable.  
But the Memory Banks are still dark.

The Memory Banks store everything: identities, profiles, stats, history.  
Without them, the network runs but remembers nothing.  
Every session starts from zero. Every player is a stranger.

Your mission: restore the Memory Banks by learning how to give the computer a working memory.

---

### What You'll Learn

- How to store a value in the computer's memory
- How to display that value
- How to take input from a user
- How to build a full character with name, health, gold, and inventory
- How to write memory to a file so it survives a restart

### Boss Battle — The Amnesia Virus

A virus has corrupted the Memory Bank's core process.  
Variables aren't storing correctly. Some display the wrong values.  
Some don't display at all.

The bug count: **6**.  
The bug types: missing `%`, wrong variable names, `set` without `=`, echo printing literal text instead of variable value.

Fix all 6. Restore the Memory Banks.
